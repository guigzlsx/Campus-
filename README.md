# Campus+

Campus+ est une maquette React/Vite de l’expérience étudiante : accueil personnalisé, recherche, agenda, carte du campus, notifications et profil numérique.

## Développement local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

Le déploiement GitHub Pages est automatisé à chaque push sur `main` via GitHub Actions.
